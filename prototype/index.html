VIZ 2.0 Back office

Admin panel prototype for a structured-products management system. Design language: shadcn/ui, targeting Spartan UI (Angular) in production.

Kit

  • Foundations: tokens, type, spacing, icons
  • Components: one page each, ordered atoms → molecules → organisms → templates
  • Navigation: the sidebar, its six areas and the app shell

Screens

  • Instruments: the list in the app shell — sidebar, page header, type tabs, search and filters
