Overview

Design system

The prototype of the VIZ 2.0 Admin panel, a management system for structured products. Design language: shadcn/ui, targeting Spartan UI (Angular) in production — the markup here maps 1:1 onto Spartan Helm components. Recipes live in assets/components.css, tokens in assets/theme.css.

One page per component: its variants, sizes and states, the rules for using it, the recipe classes, and the Spartan equivalent. They are ordered by Atomic Design — each layer built from the one above it — and a component sits in the layer it is built at, not the layer it is used at: a Badge stays an atom although it spends its life inside a table row. That order is also the order to build in, since an atom whose states are undecided makes every organism that holds it a guess. The screens themselves are the last layer, and they are under Pages.
