Components

The building blocks screens are assembled from. Each component lists its variants, sizes and states, the recipe classes to use, and the Spartan Helm equivalent. Recipes live in assets/components.css.

Button

Button

Spartan: hlmBtn · shadcn: button.tsx

Triggers an action. Base class btn plus one variant, optionally one size. Default size is 36px high.

Variants

Left to right: descending emphasis. One default per screen.

btn-default · the primary action of the screen or dialog: Save, Create

btn-secondary · a second action of equal weight next to a default

btn-outline · common secondary actions: Cancel, Export, Filter

btn-ghost · low-emphasis, toolbars, icon buttons in tables

btn-destructive · irreversible actions only, inside a confirmation

btn-link · inline in text, or "View all" style links

Sizes

Default 36px. Small 32px for dense table rows and toolbars. Large 40px is rare; use for empty-state calls to action.

With icons

Icon sits before the label. Icon-only buttons need aria-label and a tooltip.

States

Hover darkens the fill slightly. Focus shows a 3px ring (press Tab). Disabled fades to 50% and ignores the pointer. Loading swaps the icon for a spinner and disables the button.

Rules

  • One btn-default per view. If two actions compete, one of them is outline.
  • Destructive buttons never sit alone on a page; they live inside a confirmation dialog.
  • Labels are verbs: Save, Create instrument, Cancel. Not "OK", not "Yes".
  • In dialogs and forms the primary action is on the right, Cancel to its left.
  • Use <button type="button"> unless the button submits a form.

Markup

<button type="button" class="btn btn-default">Save</button>
<button type="button" class="btn btn-outline btn-sm">Cancel</button>
<button type="button" class="btn btn-default"><i class="ri-add-line"></i> New instrument</button>
<button type="button" class="btn btn-ghost btn-icon" aria-label="More actions" title="More actions">
  <i class="ri-more-2-line"></i>
</button>

Spartan equivalent: <button hlmBtn variant="outline" size="sm">Cancel</button>. Variant and size names are identical.
