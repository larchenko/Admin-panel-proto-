Overview

Components

One page per component: its variants, sizes and states, the rules for using it, the recipe classes, and the Spartan Helm equivalent. Recipes live in assets/components.css, tokens in assets/theme.css.

They are ordered by Atomic Design: each layer is built from the one above it, and a component sits in the layer it is built at, not the layer it is used at — a Badge stays an atom although it spends its life inside a table row. That order is also the order to build in: an atom whose states are undecided makes every organism that holds it a guess.
