Atoms

Switch

Spartan: hlm-switch · shadcn: switch.tsx

On/off that takes effect immediately, typically in Settings. Inside a form that has a Save button use a checkbox instead.

A switch that lives beside a form rather than in it — the instrument record's status, in the dialog header next to its badge — still acts immediately, and that is the point: the state is an act, not a field waiting for Save (decision 100). When the direction that costs something needs confirming, ask it and put the switch straight back, so it never shows a state the record does not have; the harmless direction answers itself.

End users see a maintenance page. Admins keep access.

Send a summary when a product changes status.
