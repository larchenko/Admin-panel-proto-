Metrics

Ours — no shadcn or Spartan equivalent

A row of counts between a page title and the list below it: what the set is made of, and what in it needs someone. Four cells at most, all the same width. A cell is a div when it is only a number and a button when the number filters the list — both look the same at rest, and the cursor and the pressed state say which is which.

Total instruments 248
Active 231 17 inactive

Zero is a state, not an empty cell. The count stays where it was, the colour goes, and there is nothing left to filter to — so the cell stops being a button. A strip that changes shape when the news is good cannot be read at a glance.

Small, and on its own. One cell, in a dialog header, where it must not tie with the 24px title beside it: metric-sm takes the padding down a step and the value to 20px. An <a> rather than a button when the number leads somewhere else — it gets the same hover and focus ring as a clickable cell. The instrument record's Products count is the built example (decision 97).

Products 293

Rules

  • Four cells at most. Every one has to earn the 90px it takes off the top of the list; a fifth number that nobody acts on turns the row into decoration.
  • The last cell is the one that is wrong. Left to right the row goes from what the set is to what needs doing, so the eye lands on the alert last and stays there.
  • A count only becomes a button when clicking it lands on exactly that number. Where the screen shows one page of a longer set, only a count computed over the rows can promise that.
  • Destructive here is the status colour, not an accent: a 5% tint with text in the -ink shade, the same recipe as a soft badge. One loud cell in four, and it is loud for a reason.
  • The value is 24px, the h2 step of the type ladder, but it is a number and not a heading — no h2 in this row.

Markup

<div class="metrics">
  <div class="metric">
    <span class="metric-label"><i class="ri-stack-line"></i> Total instruments</span>
    <span class="metric-value">248</span>
  </div>

  <!-- a count that filters the list: a button, with the state in aria-pressed -->
  <button type="button" class="metric metric-alert" aria-pressed="false">
    <span class="metric-label"><i class="ri-error-warning-line"></i> Failed updates</span>
    <span class="metric-value">3 <span class="metric-sub">last 24h</span></span>
  </button>

  <!-- nothing wrong: data-zero + disabled -->
</div>

<!-- one cell in a dialog header, and it leads to what it counts -->
<a class="metric metric-sm" href="/products?instrument=…">
  <span class="metric-label">Products</span>
  <span class="metric-value">293</span>
</a>
