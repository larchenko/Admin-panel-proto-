Atoms

Combobox

Spartan: hlm-popover + hlm-command · shadcn: combobox (popover.tsx + command.tsx)

One value from a list too long to scroll, found by typing. An input that filters a listbox under it as the user types; the arrows move through what is left, Enter picks, and the focus never leaves the input. It links a record to another record — Based on in the instrument form points at an existing instrument (decision 127). For a short, fixed list use the Select; for free text use the Input.

Where the list opens. The same rule as the select (decision 80): below the input, above when it does not fit below and there is more room above, capped to the room that side has, 288px at most. Behaviour in app.js. The options are whatever the listbox holds: on the Instruments screen the script fills it from the list, every instrument but the one being edited; in production a search endpoint fills it and the markup is the same.

States

The input is an Input and takes its states; the list, when open, takes the select list's. Hover and focus are the real rules, reached through data-demo (decision 104).

Rest Focus Linked Disabled

The open list, the active option and the No instrument matches line are reached by typing in the specimen above; the kit does not draw a floating layer at rest.

Rules

  • A combobox links to a record that exists; it never creates one. What the user types is a query, not a value: leaving the field without picking puts the linked name back, or empties it (decision 127).
  • The search matches the name and every identifier the record carries, the same as the list's search box (decision 44); an option shows the name and one identifier, the Bloomberg code (decision 51).
  • Empty is empty: no None option. Unlinking is the cross at the right end of the input, one word in its tooltip (decision 125).
  • The focus stays in the input; the active option is announced through aria-activedescendant. Arrows move, Enter picks, Escape closes the list and, closed, puts the linked value back; Tab closes.
  • Where the list opens and how tall it may be: the select's rule (decision 80).
  • The record being edited is never offered to itself.
