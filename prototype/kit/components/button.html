Atoms

Button

Spartan: hlmBtn · shadcn: button.tsx

Triggers an action. Base class btn plus one variant, optionally one size. Default size is 36px high.

Variants

Left to right: descending emphasis. One default per screen.

btn-default · the primary action of the screen or dialog: Save, Create

btn-outline · the second action beside a default, and quiet ones: Cancel, Export, Filter

btn-ghost · low-emphasis, toolbars, icon buttons in tables

btn-destructive · irreversible actions only, inside a confirmation

btn-link · inline in text, or "View all" style links

Sizes

The size is decided by the container, not by the button. Anything sitting on a screen is small; the default height belongs to a dialog footer and nowhere else. So the question to ask is never "how important is this action" — it is "what am I standing in".

Counted on the Instruments screen: 39 buttons, 25 of them small. The other 14 are default height and every one of them is in a footer — the delete confirmation, the discard confirmation, the record dialog. Not one is large.

btn-lg is the size btn-secondary was: it was reserved for empty-state calls to action, but the one empty state the product has — Clear all filters, when a filter matches nothing — uses btn-sm like the rest of that screen. Either an action earns it or it goes the way of 102.

With and without an icon

Every variant takes all three forms. The icon always comes before the label, and the recipe narrows the side padding when one is present (has-[>i]:px-3) so a button with an icon is not optically wider than one without.

—
  • An icon-only button is square: btn-icon sets the width to the height, so it is 36px, or 32px with btn-sm.
  • It needs both aria-label and title — the first for a screen reader, the second for the pointer. A button whose whole meaning is a glyph has to say that meaning twice.
  • In a table row it is always btn-ghost btn-icon btn-sm: the row is already a busy line, and a bordered button on every row draws thirteen boxes down the page.
  • There is no icon-only btn-link. Stripped of its text, a link variant is a bare coloured glyph — indistinguishable from an icon that is not a control at all.
  • The primary action of a screen is never icon-only. New instrument keeps its words.

  • Hover darkens the fill one step (/90); the two variants with no fill of their own take the brand tint instead. Nothing moves and nothing resizes.
  • Focus is a 3px ring in the brand hue, plus the border taking the ring colour. Destructive swaps the ring to its own hue so the ring never argues with the fill. It is :focus-visible, so a mouse click does not leave a ring behind.
  • Disabled is 50% opacity and no pointer events. Because it also ignores hover, a disabled button cannot explain itself — put the reason in a hint beside it, never in a tooltip on the button.
  • Loading is disabled plus aria-busy="true", with the icon swapped for ri-loader-4-line animate-spin. The label should move to the progressive verb at the same time — Save becomes Saving… — and the width is left to change with it; a spinner on an unchanged label reads as a stuck page.
  • Ghost at rest is invisible, which the first column shows plainly. That is the point of it, and also its limit: it only works where the container already says a control is there — a toolbar, a row, a header.

Rules

  • One btn-default per view. If two actions compete, one of them is outline.
  • There is no btn-secondary. shadcn and Spartan ship one; this product never found it a job, and a second way to draw a Cancel is how two Cancels end up on one screen (decision 102).
  • Destructive buttons never sit alone on a page; they live inside a confirmation dialog.
  • Labels are verbs: Save, Create instrument, Cancel. Not "OK", not "Yes".
  • In dialogs and forms the primary action is on the right, Cancel to its left.
  • Use <button type="button"> unless the button submits a form.

Markup

<button type="button" class="btn btn-default">Save</button>
<button type="button" class="btn btn-outline btn-sm">Cancel</button>
<button type="button" class="btn btn-default"><i class="ri-add-line"></i> New instrument</button>
<button type="button" class="btn btn-ghost btn-icon" aria-label="More actions" title="More actions">
