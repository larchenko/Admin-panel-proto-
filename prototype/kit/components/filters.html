Filters

Spartan: hlm-popover · shadcn: popover.tsx

A list with more than about four filters does not put them in the toolbar: past that they eat the width the search box and the primary action need, and none of them is used often enough to earn a permanent slot. They go in one panel behind a Filters button, and the button carries the number of them that are on (decision 89). Because a shut panel hides the query, a chip row sits under the toolbar: one chip per filter the panel holds, each clearing itself, so the list is never narrowed by something invisible. A filter whose own control is on screen — the search box, a type tab, a summary cell that filters — gets no chip; two copies of one state is one too many. Nothing is applied by a button: every change filters at once, so the footer count moves while the panel is open. Clear all means all — the panel, the search box and any filter parked in a control elsewhere.

Fields are laid out two across, which is what keeps the panel short enough to open downward under the toolbar. A pair of fields that is one filter — pick a field, then Empty or Filled — is ruled off as its own group with an overline: the Instruments list asks that of all twelve identifiers that way instead of carrying twelve controls (decision 90). Until both halves are set the filter does nothing, and the second select stays disabled so that half a filter never looks like a whole one.
