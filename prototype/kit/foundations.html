Foundations

Everything a component is allowed to use: colour tokens, type scale, spacing, radius, shadow and icon rules. Values shown are read live from theme.css, so this page never goes stale. Font and colours are placeholders until a brand exists.

Colour

Tokens come in pairs: a surface and the text that sits on it (-foreground). Components use the pair, never a raw colour. Values are OKLCH: lightness 0–1, chroma, hue.

Radius

One base token --radius (), the rest is derived. Change the base and every corner follows.

rounded-sm

badges, code, small chips

rounded-md

buttons, inputs, menu items

rounded-lg

cards, dialogs, popovers

rounded-xl

large containers, empty states

Shadow

Shadows mark elevation only. Content that sits on the page uses a border, not a shadow.

border only

cards, tables, panels

shadow-xs

buttons, inputs (subtle lift)

shadow-md

dropdowns, popovers

shadow-lg

dialogs

Icons

RemixIcon, used as an icon font: <i class="ri-search-line"></i>. The icon inherits the text colour and its size follows font-size.

Rule 1 · Line by default, fill for "on"

Fill marks the active navigation item or a selected state. Nothing else.

Home Home (active) Watch Watching

Rule 2 · Three sizes

Inline with text 16px, navigation and toolbar 20px, empty states 32px+.

16px · text-base · in buttons, inputs, table cells


20px · text-xl · sidebar nav, toolbar icon buttons


30px · text-3xl · empty states, illustrations

Rule 3 · Icon + label, or icon with a tooltip

An icon alone must have an accessible name (aria-label) and a tooltip. Decorative icons get aria-hidden.

Spartan mapping

Token names and the OKLCH format match Spartan UI's theme file one to one. A developer copies the :root block from theme.css into the Angular project's global styles and the theme is done. Icons map to @ng-icons/remixicon; the icon name stays the same (ri-search-line → remixSearchLine).
