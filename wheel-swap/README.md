# Wheel Swap

Приміряйте нові диски на своє авто. Завантажте фото авто, фото диска (з магазину на
білому фоні або на іншому авто), вкажіть розмір поточного й нового диска — додаток
знайде всі видимі колеса, підставить новий диск у перспективі кожного колеса і
перемалює профіль шини під новий розмір (зовнішній діаметр колеса не змінюється).

```bash
make setup && make serve   # http://localhost:8000
```

Працює на CPU; перший запуск завантажує ваги моделей (~400 МБ) з релізів Ultralytics
і rembg на GitHub.

Додаток відмовляє з поясненням, якщо:
- на фото авто не видно дисків (строго спереду чи ззаду);
- на фото диска коло диска видно не повністю — бракує фрагмента для коректної візуалізації;
- фото має замалу роздільну здатність (рахується реальна деталізація, тож розтягнута
  мініатюра не пройде).
